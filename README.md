# مولّد رابط تقييم Google لبطاقة NFC

صفحة عربية مستقلة لاستخراج رابط التقييم المباشر لنشاط تجاري وتجهيزه للنسخ إلى بطاقة NFC. تتعامل مع روابط `share.google` عبر خدمة خلفية لا تتبع إلا تحويلات Google.

## التشغيل

من مجلد المشروع:

```powershell
cd google_review_link_generator
py -m pip install -r requirements.txt
$env:GOOGLE_MAPS_API_KEY = "مفتاح خادمي مقيّد بواجهة Places API (New)"
py -m uvicorn app:app --host 127.0.0.1 --port 8080
```

ثم افتح `http://localhost:8080`.

## آلية العمل

- عند إدخال رابط `maps.app.goo.gl`، يفك الخادم التحويل ويستخرج CID من رابط Maps النهائي، ثم يحوّله إلى Place ID عبر endpoint Maps preview العام؛ هذا المسار لا يحتاج API key، لكنه يعتمد على واجهة Google داخلية غير موثقة وقد تتغير.
- عند إدخال رابط `share.google`، يفك الخادم التحويلات ضمن نطاقات Google فقط. إذا أعاد Google `Place ID` يستخدمه مباشرةً؛ وإذا أعاد `kgmid` واسم النشاط، يبحث عن `Place ID` عبر Places API ويعرض الفروع المطابقة للاختيار.
- عند إدخال رابط `https://g.page/r/{ID}` أو `https://g.page/r/{ID}/review`، تحافظ الصفحة على المعرّف نفسه وتنتج `https://g.page/r/{ID}/review`.
- إذا احتوى رابط Google Maps على `Place ID`، تنشئ الصفحة رابط التقييم مباشرةً.
- لا تطلب الصفحة اسم النشاط أو عنوانه أو مفتاح API. المفتاح المطلوب لتحويل `kgmid` في بعض روابط `share.google` يُضبط مرة واحدة على الخادم بمتغير البيئة `GOOGLE_MAPS_API_KEY`، ولا يصل إلى المتصفح.
- `kgmid` و`Place ID` ورمز `g.page/r/{ID}` معرّفات مختلفة. لا يمكن اشتقاق رمز `g.page` من رابط مشاركة عام؛ لذلك ينشئ التطبيق رابط Google الرسمي المبني على Place ID، ويستخدم صيغة `g.page` فقط عندما يكون رمزها موجوداً في رابط الإدخال.

## إعداد Google Places

أنشئ مفتاحاً في Google Cloud، فعّل Places API (New)، واضبط الفوترة إذا تطلبها حسابك. قيّد المفتاح بالخدمة المطلوبة وعنوان IP الخادم، واحفظه كمتغير بيئة `GOOGLE_MAPS_API_KEY` كما في أمر التشغيل أعلاه. لا تضعه في الواجهة أو المستودع. يلزم المفتاح فقط عندما يعيد رابط `share.google` معرّف `kgmid` بدلاً من CID أو Place ID؛ روابط `maps.app.goo.gl` التي تحتوي CID تعمل من دونه.

## قابلية التوسعة

فصل قراءة الروابط، فك التحويل، وبناء رابط التقييم يجعل إضافة خدمات لاحقة مثل إنشاء QR، تنزيل بطاقة قابلة للطباعة، أو قوالب متعددة أمراً مباشراً. روابط `share.google` تُرسل إلى الخادم للفك والبحث؛ لا يخزّن التطبيق الروابط.
